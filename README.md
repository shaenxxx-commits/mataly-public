# MATALY

> **Статус:** дослідження поля / v0.1
> Проєкт на етапі дослідження поля. Блок «Світ Рослин» закрито на рівні публічних джерел; триває карта поля. Документаційна основа формується поступово.

## Що це

MATALY — особистий дослідницький проєкт, що досліджує агросередовище навколо компанії «Світ Рослин». Компанія — точка входу в поле, не центр дослідження. 

Проєкт не є корпоративним. Автор не представляє інтереси компанії «Світ Рослин» і не діє від її імені. Компанія — об'єкт спостереження (одна з точок входу), а не замовник і не власник проєкту.

## Мета

Дослідити агросередовище із застосуванням дослідницького підходу проєкту Envoy:

1. Дослідити поле та зібрати перевірені спостереження.
2. Виявити закономірності й сформувати гіпотези.
3. Перевірити можливі напрями та ніші.
4. Лише після дослідження визначати можливості практичної реалізації.

## Що не визначено наперед

Кінцева ніша, архітектура та форма практичної реалізації не визначені. Попередні гіпотези майбутніх напрямів — персональна контент-фабрика та персональна інтерактивна база знань — це [ГІПОТЕЗИ], а не затверджена модель проєкту.

## Методологічна основа

- **KARCAS-DDA** — каркас Documentation-Driven Architecture (DDA). Документація відображає фактичний стан проєкту, рішення, обмеження та невизначеності. Репозиторій: https://github.com/shaenxxx-commits/karcas-dda
- **Envoy** — методологічний орієнтир для дослідження поля. Принцип: спочатку поле й спостереження, потім модель і пошук можливостей. Репозиторій: https://github.com/shaenxxx-commits/envoy

Структура Envoy не копіюється механічно; методологія застосовується відповідно до потреб MATALY.

## Мінімальне ядро

- `README.md` — цей файл.

Решта документів (бібліотека) підключається за тригером, а не наперед.

## Підключені документи бібліотеки

- `meta/agent-rules.md` — правила роботи LLM-агента в MATALY.
- `meta/handoff-protocol.md` — протокол передачі контексту між сесіями й агентами.
- `meta/open-questions.md` — відкриті питання (append-only).
- `records/README.md` — формат первинних записів спостережень.
- `records/001`–`005` — записи спостережень (Світ Рослин: офіційні джерела, юридичні особи, торгові точки, судові справи; карта поля: рамка).

Решта — за тригером (див. `CURRENT_STATE.md`).

## Для людини

## Для LLM-агента

Правила роботи агента — `meta/agent-rules.md`. Протокол передачі контексту — `meta/handoff-protocol.md`. При старті нової сесії або нового агента — обов'язкова процедура старту з `meta/handoff-protocol.md` §6. Відкриті питання — `meta/open-questions.md`.

KARCAS-DDA `meta/agent-rules.md` і `meta/handoff-protocol.md` — джерело базових правил і failure cases; підключаються посиланням, не копіюванням (I14).
